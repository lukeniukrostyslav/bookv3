### Акт I — вход в загадку
**Глава 1:** годовщина исчезновения Эдриана → ключ 314 → невозможный адрес → появление Отеля.
**Глава 2:** Лев входит → понимает, что Отель знает его фамилию → замечает запись Эдриана → получает доступ к невозможной комнате.
**Глава 3:** знакомство с Мирой → предупреждение → реакция на имя Эдриана → Лев понимает, что она скрывает знание.
**Глава 4:** правила → Лев проверяет слова Миры → три стука → появляется невозможный четвёртый стук.
**Глава 5:** ключ открывает 314 → предметы семьи → фотография из будущего → голос Эдриана.
**Глава 6:** гость из будущего → доказательство знания будущего → предупреждение → исчезновение.
**Глава 7:** попытка уйти → лифт без кнопок → мысль о брате направляет лифт → этаж Арденов.
**Глава 8:** встреча с возможным Эдрианом → он жив → он не пленник → просит Миру вывести Льва.

**Поворот I:** Лев узнаёт, что поиск брата может быть опаснее, чем его отсутствие.

### Акт II — исследование превращается в расследование
**Глава 9:** записи Эдриана в разные годы → запись из будущего → вопрос о количестве его появлений.
**Глава 10:** ресторан воспоминаний → детство Льва → Мира избегает своего блюда → тарелка для Эдриана.
**Глава 11:** голос за стеной → сервисный проход → предупреждение о смерти Льва.
**Глава 12:** несуществующий этаж → незавершённые пространства → дверь с датой исчезновения.
**Глава 13:** Библиотека несбывшегося → книга семьи → новая запись появляется прямо перед Львом.
**Глава 14:** фотографии Миры в разные годы → остановленное старение → связь с Эдрианом.
**Глава 15:** фотографии будущего → Лев у неизвестной двери → Управляющий на заднем плане.
**Глава 16:** Эдриан объясняет добровольность → катастрофический вариант возвращения → Лев узнаёт о своей возможной роли хранителя.

**Поворот II:** появление Льва изменило систему Отеля и создало новую ветвь будущего.

### Акт III — цена знания
**Глава 17:** Лев видит будущее без Эдриана и Миры → люди помнят его иначе → намёк на исчезновение самого Льва.
**Глава 18:** три устойчивых будущих → каждое имеет цену → Лев понимает, что идеального решения нет.
**Глава 19:** закон цены → риск потерять воспоминание об Эдриане → желание спасти брата становится опасным.
**Глава 20:** город после полуночи → несколько часов вперёд → последствия ещё не совершённого события → некролог Льва.
**Глава 21:** полная история Эдриана → он стал хранителем ради защиты → признание, что Лев изначально мог занять его место.
**Глава 22:** комната смерти → несколько вариантов смерти → один связан с попыткой спасти Эдриана.
**Глава 23:** Управляющий предлагает контролируемый безопасный вариант → раскрывает часть истории Миры → доверие Льва к ней рушится.
**Глава 24:** возникает четвёртое будущее → его причина появляется только после наблюдения → Управляющий не способен его просчитать.

**Большой поворот:** сам факт присутствия Льва создал вариант, которого система не знала.

**Глава 25:** Отель начинает менять архитектуру → двери открываются одновременно → все пути ведут к неизвестному уровню.

### Акт IV — выбор
**Глава 26:** Последний этаж → соприкосновение вариантов → механизм вероятностей.
**Глава 27:** механизм не создаёт будущие, а распределяет вероятность → Управляющий использовал его для контроля.
**Глава 28:** изменение системы требует личного якоря → Лев рискует памятью.
**Глава 29:** последний разговор братьев → Эдриан признаёт, что слишком долго решал за Льва.
**Глава 30:** Лев отказывается выбирать навязанное будущее → ломает принцип принуждения → платит частью памяти.
**Глава 31:** Отель исчезает из обычного мира → Лев возвращается → часть прошлого становится неясной → Эдриан получает возможность вернуться.
**Глава 32:** Лев живёт дальше → появляется новая карточка → «Первый Отель был не единственным».
