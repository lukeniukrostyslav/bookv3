# OUTLINE — BOOK 1

01. Поезд без номера — Марк попадает в Ноктюрн.
02. Город на воде — первые правила города и первые опасности.
03. Рынок потерянного — Марк узнаёт цену воспоминаний.
04. Настоящие имена — способность Марка становится очевидной.
05. Дом, который помнит — след матери.
06. Серые люди — преследователи из обычного мира.
07. Архив — поиск записи о Вейлах.
08. Девочка без имени — тайна Элизы.
09. Башня обратного времени — значение 11:47.
10. Король Ноктюрна — встреча с властью города.
11. Письмо из будущего — новое послание матери.
12. Охота — Марк становится целью.
13. Под городом — скрытый слой Ноктюрна.
14. Имя короля — опасное открытие.
15. Последний поезд — финальная часть первой дуги.
16. Цена возвращения — выбор Марка.
17. 11:47 — раскрытие первого большого секрета.
18. Граница — возвращение и последствия.
19. То, чего не было — новый поворот.
20. Город открывает глаза — финал книги и дверь во вторую.

Роман целится в 80–120 тысяч слов. Количество глав может изменяться ради качества.
